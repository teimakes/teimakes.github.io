## 1. 자연어 처리의 주요 작업

**자연어 처리(Natural Language Processing, NLP)**는 사람이 쓰는 언어를 컴퓨터가 분석하고 생성하도록 만드는 분야입니다. LLM이 등장하기 전에는 작업에 맞는 모델을 각각 만드는 경우가 많았습니다.

- **텍스트 분류:** 영화 리뷰를 긍정 또는 부정으로 분류합니다.
- **언어 모델링:** 앞에 나온 텍스트를 바탕으로 다음 단어의 확률을 예측합니다.
- **기계 번역:** 입력 문장을 다른 언어로 바꿉니다.
- **태깅:** 문장 속 단어에 품사나 사람·장소 같은 이름표를 붙입니다.

### 언어 모델은 다음 단어를 어떻게 예측할까?

“나는 아침마다 커피를 한 잔씩 ___.”이라는 문장이 있다면 모델은 빈칸에 들어갈 후보의 확률을 예측합니다. 예를 들어 ‘마신다’ 70%, ‘마셨다’ 15%, ‘만든다’ 10%처럼요. 이 숫자들은 설명을 위한 가상 예시입니다.

`P(xₜ | x₁, x₂, …, xₜ₋₁)`은 **앞의 단어들이 주어졌을 때 다음 단어 xₜ가 나올 확률**을 뜻합니다. 선택한 단어를 뒤에 붙이고 이 과정을 반복해 텍스트를 생성하는 방식을 **자기회귀 생성(autoregressive generation)**이라고 합니다. 실제 LLM은 대개 단어 대신 토큰이라는 단위로 처리합니다.

<a id="ngram"></a>
## 2. 단어 빈도로 다음 단어 예측하기: N-gram

신경망이 등장하기 전에도 연구자들은 텍스트에서 단어가 얼마나 자주 나오는지 세어 언어 모델을 만들었습니다.

### 유니그램: 단어 하나씩 보기

어떤 말뭉치에서 고양이 40번, 강아지 30번, 토끼 20번, 햄스터 10번이 등장했다면 전체 100번 중 고양이의 확률은 `40 / 100 = 0.4`입니다. **유니그램(unigram)** 모델은 이렇게 개별 단어의 빈도를 사용합니다.

단점은 앞의 문맥을 고려하지 않는다는 것입니다. “고양이가 생선을 ___”과 “고양이가 지붕 위에 ___”에서도 같은 단어별 확률을 사용합니다.

### 바이그램과 N-gram: 앞 단어 참고하기

**바이그램(bigram)** 모델은 바로 앞 단어를 참고합니다. 학습 데이터에서 ‘커피를’ 뒤에 ‘마신다’가 8번, ‘만든다’가 2번 나왔다면, `P(마신다 | 커피를) = 8 / 10 = 0.8`로 추정할 수 있습니다.

- **유니그램:** 각 단어의 빈도만 사용합니다.
- **바이그램:** 바로 앞 단어 하나를 참고합니다.
- **트라이그램:** 앞 단어 두 개를 참고합니다.
- **N-gram:** 앞의 단어 최대 N−1개를 참고합니다.

앞의 단어를 더 많이 보면 문맥을 더 잘 반영할 것 같지만, 가능한 조합의 수가 급격히 늘어 충분한 예시를 확보하기 어려워집니다. 이를 **희소성(sparsity)** 문제라고 합니다.

### 처음 보는 단어 조합은?

학습 중 본 적 없는 조합의 확률을 0으로 두면 자연스러운 문장도 불가능하다고 판단할 수 있습니다. 이를 완화하기 위해 관찰되지 않은 조합에도 작은 확률을 배분하는 **스무딩(smoothing)**을 사용합니다. 긴 문맥의 통계가 부족할 때 더 짧은 문맥의 통계를 함께 활용하는 방법도 있습니다.

<a id="perplexity"></a>
## 3. 언어 모델 평가하기: 퍼플렉서티

**퍼플렉서티(perplexity, PPL)**는 실제 텍스트의 다음 토큰에 모델이 얼마나 높은 확률을 주었는지 요약하는 지표입니다. 같은 평가 조건에서는 낮을수록 정답에 더 높은 확률을 부여한 것입니다.

매번 10개의 후보를 똑같이 가능하다고 보는 단순한 경우 퍼플렉서티는 10입니다. 실제 모델에서는 문맥마다 확률 분포가 달라지므로 언제나 후보의 개수로 그대로 해석해서는 안 됩니다.

> **비교할 때 주의:** 서로 다른 데이터셋이나 서로 다른 토큰화 방식으로 계산한 퍼플렉서티는 단순 비교하기 어렵습니다. 단어 단위인지 문자 단위인지도 확인해야 합니다.

<a id="bow"></a>
## 4. 문장을 숫자로 바꾸기: Bag of Words

기계학습 모델이 텍스트를 처리하려면 텍스트를 숫자로 표현해야 합니다. 그중 단순한 방법이 **Bag of Words(BoW, 단어 주머니)**입니다.

조사와 어미를 단순화한 두 문장을 생각해 봅시다.

- 문장 A: ‘고양이, 생선, 좋아하다’
- 문장 B: ‘강아지, 고기, 좋아하다’

전체 단어 목록을 `[고양이, 강아지, 생선, 고기, 좋아하다]`로 정하면 A는 `[1, 0, 1, 0, 1]`, B는 `[0, 1, 0, 1, 1]`로 표현할 수 있습니다. 각 숫자는 단어의 등장 여부나 횟수를 나타냅니다.

BoW는 스팸 분류처럼 단어의 존재가 중요한 문제에서 유용할 수 있지만, 단어의 **순서**를 잃고 비슷한 의미의 단어도 별개의 차원으로 취급합니다. 단어 종류가 많으면 벡터는 크고 대부분의 값이 0인 희소 벡터가 됩니다.

<a id="embeddings"></a>
## 5. 단어의 의미 관계 담기: 임베딩

**단어 임베딩(word embedding)**은 단어를 비교적 짧은 숫자 벡터로 나타냅니다. 비슷한 문맥에서 쓰이는 단어들이 벡터 공간에서도 가까워지도록 학습할 수 있습니다.

예를 들어 ‘고양이’와 ‘강아지’는 ‘밥을 먹는다’, ‘소파에서 잔다’ 같은 비슷한 주변 표현과 함께 등장할 수 있습니다. 모델은 이런 공통 패턴을 활용해 비슷한 표현을 학습합니다. 실제 벡터의 각 차원이 사람이 바로 해석할 수 있는 개별 의미를 반드시 담당하는 것은 아닙니다.

### Word2Vec과 GloVe

**Word2Vec**의 대표적인 학습 방식은 두 가지입니다.

- **CBOW:** 주변 단어를 보고 가운데 단어를 예측합니다.
- **Skip-gram:** 가운데 단어를 보고 주변 단어를 예측합니다.

**GloVe**는 말뭉치 전체에서 두 단어가 주변에 함께 등장하는 **동시 출현 통계**를 활용합니다. 두 방식 모두 언어 데이터의 통계적 패턴을 통해 단어 관계를 학습합니다.

### 같은 단어도 문맥에 따라 뜻이 달라진다

‘은행에서 돈을 찾았다’의 은행과 ‘가을이 되니 은행이 노랗게 물들었다’의 은행은 의미가 다릅니다. 단어마다 하나의 고정 벡터를 부여하는 정적 임베딩은 이 차이를 충분히 표현하기 어렵습니다. 이 문제는 나중에 **문맥 기반 표현(contextual representation)**으로 이어집니다.

또 임베딩은 학습 데이터에 담긴 편향을 반영할 수 있으므로 벡터의 거리를 객관적인 진실로 받아들여서는 안 됩니다.

<a id="rnn"></a>
## 6. 순서를 고려하기: RNN과 LSTM

**순환 신경망(Recurrent Neural Network, RNN)**은 문장의 단어를 순서대로 읽으면서 지금까지의 정보를 **은닉 상태(hidden state)**에 담습니다.

‘나는 어제 친구와 영화를 봤다’라는 문장을 처리한다면, 첫 단어로 상태를 만든 뒤 이전 상태와 다음 단어를 사용해 상태를 계속 갱신합니다. 기본적인 갱신식은 다음과 같습니다.

```text
hₜ = f(Wₓxₜ + Wₕhₜ₋₁ + b)
```

여기서 `xₜ`는 현재 입력, `hₜ₋₁`은 이전 상태, `hₜ`는 새 상태입니다. `Wₓ`, `Wₕ`, `b`는 학습되는 파라미터이고 `f`는 비선형 활성화 함수입니다. 핵심은 **현재 단어와 이전까지 읽은 정보를 함께 사용한다**는 것입니다.

### 긴 문맥을 기억하기 어려운 이유

문장이 길면 앞부분의 정보가 뒤까지 전달되는 과정에서 약해질 수 있습니다. 학습 과정에서도 먼 시점까지 전달되는 기울기가 작아지는 **기울기 소실(vanishing gradient)**이 발생할 수 있습니다. 반대로 기울기가 지나치게 커지는 문제도 있습니다.

### LSTM과 GRU

**LSTM**과 **GRU**는 이런 문제를 완화하기 위해 만들어진 RNN 계열 모델입니다. LSTM은 게이트 구조를 사용해 어떤 정보를 기억하고 잊을지, 어떤 정보를 내보낼지 조절합니다. 긴 의존 관계의 학습에 도움을 주지만 모든 문맥을 완벽하게 기억하는 것은 아닙니다.

RNN은 기본적으로 이전 상태를 계산해야 다음 상태를 계산할 수 있으므로, 긴 문장을 학습할 때 병렬 처리에도 제약이 있습니다.

<a id="pretraining"></a>
## 7. 언어 지식 재사용하기: 사전학습과 미세조정

어떤 모델이 대량의 텍스트를 읽으며 배운 지식을 다른 작업에 재사용할 수 있다면, 새로운 작업마다 처음부터 학습할 필요가 줄어듭니다.

- **사전학습(pre-training):** 대량의 텍스트로 다음 단어 예측 같은 작업을 수행하며 언어의 패턴을 미리 익힙니다.
- **미세조정(fine-tuning):** 사전학습한 모델을 긍정·부정 분류처럼 특정 작업의 데이터로 추가 학습합니다.

예를 들어 언어 모델을 사전학습한 뒤 영화 리뷰와 감성 라벨을 사용해 분류 모델로 조정할 수 있습니다. 미리 익힌 언어 패턴은 특히 라벨이 있는 데이터가 적을 때 도움이 될 수 있습니다.

RNN의 은닉 상태는 현재 단어뿐 아니라 앞서 읽은 문맥의 영향을 받습니다. 따라서 같은 ‘은행’이라도 문맥에 따라 다른 표현을 만들 수 있습니다. 이런 생각은 ELMo와 BERT 같은 문맥 기반 표현으로 이어집니다. 다만 모델마다 앞쪽 문맥만 보는지, 양쪽 문맥을 활용하는지는 다릅니다.

<a id="attention"></a>
## 8. 번역과 어텐션

기계 번역에서는 입력과 출력의 길이와 단어 순서가 서로 다를 수 있습니다. 초기 신경망 번역에서 널리 쓰인 **인코더–디코더** 구조는 인코더가 입력을 읽고 디코더가 그 정보를 바탕으로 번역문을 생성합니다.

긴 문장의 모든 정보를 제한된 크기의 벡터 하나에 담으려 하면 필요한 정보가 빠질 수 있습니다. **어텐션(attention)**은 디코더가 단어를 출력할 때마다 입력의 여러 위치를 서로 다른 비율로 참고하도록 합니다.

번역 과정에서 주어를 생성할 때는 입력의 주어에, 목적어를 생성할 때는 관련된 입력 부분에 더 높은 가중치를 줄 수 있습니다. 이 가중치는 모델이 학습하며, 반드시 사람이 생각하는 단어 대응과 정확히 일치하는 것은 아닙니다.

```text
cₜ = Σᵢ αₜ,ᵢ hᵢ
```

`hᵢ`는 입력 각 위치의 벡터, `αₜ,ᵢ`는 출력 시점 t에서 해당 위치에 부여한 가중치, `cₜ`는 가중합으로 만든 문맥 벡터입니다. 즉, **출력할 때마다 입력의 정보를 필요한 비율로 모아 사용합니다.**

<a id="transformer"></a>
## 9. 셀프 어텐션과 트랜스포머

2017년에 발표된 **트랜스포머(Transformer)**는 RNN의 순환 구조 대신 어텐션을 중심으로 시퀀스를 처리하도록 제안된 구조입니다. 원래 발표된 모델은 기계 번역을 위한 인코더–디코더 모델이었습니다.

### 같은 문장 안을 살펴보는 셀프 어텐션

**셀프 어텐션(self-attention)**은 한 문장 안의 각 위치가 다른 위치의 정보를 참고하도록 합니다. 예를 들어 ‘민지는 지수에게 책을 빌려주었다. 그녀는 고맙다고 말했다’에서 ‘그녀’가 누구를 가리키는지 살피려면 앞에 등장한 인물과 문맥을 함께 고려해야 합니다.

각 위치는 다른 위치의 정보를 가중합해 새 표현을 만듭니다. 실제 트랜스포머는 여러 어텐션 헤드와 여러 층을 사용합니다. 단어의 순서도 구분할 수 있도록 **위치 정보**를 함께 제공합니다.

트랜스포머는 RNN보다 학습 중 여러 위치의 계산을 병렬화하기 쉽습니다. 다만 자기회귀 방식의 텍스트 생성에서는 새 토큰을 만든 뒤 다음 토큰을 생성하므로 출력 과정의 순차성은 남아 있습니다.

<a id="bert-gpt"></a>
## 10. BERT와 GPT의 차이

트랜스포머는 구조와 학습 목표를 다르게 활용한 여러 모델의 기반이 되었습니다.

### BERT: 주변 문맥을 보고 빈칸 채우기

**BERT**는 트랜스포머 인코더를 기반으로 합니다. 대표적인 사전학습 방식인 **마스크 언어 모델링**에서는 ‘나는 아침에 [MASK]를 마셨다’처럼 일부 토큰을 가리고 주변 문맥을 활용해 이를 예측합니다. 학습된 표현을 분류나 개체명 인식 등에 미세조정할 수 있습니다.

### GPT: 앞의 내용을 보고 이어 쓰기

**GPT 계열**은 트랜스포머 디코더 기반으로, 앞의 토큰을 보고 다음 토큰을 예측합니다. 예측한 토큰을 포함해 다음 토큰을 다시 예측함으로써 텍스트를 생성합니다.

이후에는 사용자의 요청을 더 잘 따르도록 지도 미세조정과 사람의 선호를 반영한 학습 등 후속 학습도 활용됩니다. 오늘날 대화형 AI의 동작을 이해할 때는 사전학습과 후속 학습을 함께 살펴보는 것이 좋습니다.

<a id="summary"></a>
## 11. 발전 흐름 한눈에 보기

- **N-gram:** 단어의 출현 빈도로 다음 단어를 예측합니다. 긴 문맥은 충분한 예시를 얻기 어렵습니다.
- **단어 임베딩:** 단어를 밀집 벡터로 표현해 단어 간 관계를 학습합니다. 고정된 벡터 하나로는 문맥에 따른 의미 차이를 표현하기 어렵습니다.
- **RNN·LSTM:** 이전 상태를 갱신하며 순서와 문맥을 처리합니다. 긴 의존 관계와 순차 계산이 과제입니다.
- **사전학습·미세조정:** 언어 지식을 미리 학습하고 특정 작업에 맞게 조정해 재사용합니다.
- **어텐션:** 출력할 때마다 관련된 입력 위치를 참고해 입력을 하나로 압축하는 부담을 줄입니다.
- **트랜스포머:** 순환 구조 대신 셀프 어텐션을 사용해 학습을 병렬화합니다. 긴 문맥에는 여전히 계산 비용이 듭니다.
- **BERT·GPT:** 트랜스포머 사전학습을 문맥 표현과 텍스트 생성에 활용합니다. 작업에 따른 평가와 후속 학습도 필요합니다.

<a id="practice"></a>
## 12. 직접 해 보는 실습과 학습 순서

원문은 IMDB 영화 리뷰와 WikiText-2를 중심으로 실습을 제공합니다. 아래는 핵심 아이디어를 직접 확인할 수 있도록 새롭게 정리한 실습입니다.

### 실습 1. 바이그램 모델 만들기

1. [WikiText-2](https://huggingface.co/datasets/Salesforce/wikitext)의 학습 데이터를 불러옵니다.
2. 연속된 두 단어의 등장 횟수를 셉니다.
3. 시작 단어를 정하고, 다음 단어를 등장 빈도에 비례해 선택합니다.
4. 이를 반복해 문장을 생성합니다.

**생각해 보기:** 이웃한 두 단어는 자연스러운데 전체 문장은 왜 어색할까요? 한 번도 보지 못한 단어 쌍을 어떻게 처리할 수 있을까요?

### 실습 2. 영화 리뷰 분류하기

1. [IMDB 영화 리뷰 데이터셋](https://huggingface.co/datasets/stanfordnlp/imdb)을 불러옵니다.
2. 리뷰를 BoW 또는 TF-IDF 벡터로 바꿉니다.
3. 로지스틱 회귀 분류기를 학습하고 긍정·부정 분류 정확도를 측정합니다.
4. 틀린 리뷰를 직접 읽고 오류의 원인을 분석합니다.

**생각해 보기:** 부정 표현과 반어법은 분류 결과에 어떤 영향을 줄까요? 정확도가 높아도 실패하는 사례는 무엇일까요?

### 실습 3. 어텐션이 필요한 이유 관찰하기

1. `3174 → 4713`처럼 무작위 숫자열과 순서를 뒤집은 정답을 만듭니다.
2. 인코더–디코더를 학습하고 입력 길이별 정확도를 측정합니다.
3. 어텐션을 추가한 모델을 학습해 같은 조건에서 비교합니다.
4. 출력 위치마다 어느 입력에 높은 가중치를 부여하는지 시각화합니다.

**생각해 보기:** 입력이 길어지면 두 모델의 성능은 어떻게 달라질까요? 어텐션 가중치는 모델의 동작을 어디까지 설명할 수 있을까요?

### 추천 학습 순서

먼저 각 기술이 해결하려던 문제를 중심으로 전체 흐름을 읽습니다. 다음으로 바이그램과 BoW를 직접 구현하고, 임베딩과 RNN을 공부한 뒤 어텐션 실습을 진행해 보세요. 마지막으로 셀프 어텐션과 BERT·GPT의 학습 목표를 비교하면 지금의 LLM과 연결하기 좋습니다.
