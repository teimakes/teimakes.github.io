# Vibe(코딩 에이전트) 활용 레시피

Vibe는 저장소를 직접 읽고 수정하는 코딩 에이전트입니다. 이 cookbook 스크립트를 실제 프로젝트로 확장할 때 유용한 레시피입니다.

## 1. 대상을 먼저 고정한다

"이 저장소(`owner/repo`)를 클론해서 `cookbook/mistral` 스크립트를 내 프로젝트 구조에 맞게 옮겨 줘"처럼 저장소와 경로를 분명히 요청합니다.

## 2. 작업을 단위별로 나눠 의뢰한다

- "코드만 고쳐 줘" / "리뷰만 해 줘" / "테스트만 추가해 줘"처럼 수정·검토·실행을 분리하면 결과가 안정적입니다.
- 한 번에 "전부 리팩터링하고 테스트 만들고 문서화해 줘"라고 시키면 빗나가는 경우가 많습니다.

## 3. 저장소 규칙을 먼저 읽게 한다

"`AGENTS.md`, `CONTRIBUTING.md`, `README.md`를 먼저 읽고 그 규칙을 따라 줘"라고 요청하면 저장소의 언어·형식·커밋 규칙을 자연스럽게 따릅니다.

## 4. 비밀은 환경변수로

API 키, 토큰은 `.env`나 환경변수로만 관리하고, "비밀키는 절대 코드나 커밋에 넣지 마"라고 명시합니다. `.env`는 `.gitignore`에 있는지도 확인하게 합니다.

## 5. 변경은 브랜치 + PR로

"브랜치를 따서 커밋하고 PR을 열어 줘"라고 요청하면 변경 이력이 깔끔하게 남고, 리뷰를 붙이기 쉽습니다.

## 6. 검증까지 맡긴다

"모든 스크립트를 `python -m py_compile`으로 검사해 줘", "린트와 타입체크를 돌려 줘", "실제 API 키로 01~03번만 실행해서 결과를 보여 줘"처럼 검증 단계를 함께 의뢰하면 완성도가 올라갑니다.

## 7. 모호하면 되묻는다

요청이 모호하면 에이전트가 임의로 채우기보다, "이 부분은 A/B 중 어느 쪽으로 할까요?"처럼 확인 질문을 하도록 유도하면 더 정확합니다.
